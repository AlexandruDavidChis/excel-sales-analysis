# Sales Performance Analysis — Excel

## Project Overview
This personal project analyzes sales data using Microsoft Excel to identify trends and evaluate business performance.

The project includes a dashboard that provides a visual overview of sales performance, along with separate analysis sheets and written interpretations.

**Disclaimer:** All data used in this project is fictional and was created for learning and demonstration purposes. It does not represent a real company or actual sales transactions.

## Project Objectives
- Analyze monthly sales performance.
- Compare sales across regions.
- Identify the top 4 customers by sales.
- Evaluate total sales by product.
- Present key findings through charts and a dashboard.

## Tools Used
- Microsoft Excel
- Excel formulas
- Pivot Tables
- Charts and data visualization
- Dashboard design

## Key Skills Demonstrated
- Data organization and analysis
- Sales performance reporting
- Data visualization
- Business insights and interpretation

## Project Structure
- **Sales Analysis:** Source sales data.
- **Monthly Sales:** Analysis of sales by month.
- **Sales by Region:** Comparison of regional sales.
- **Top 4 Customers:** Identification of the highest-performing customers.
- **Sales by Product:** Analysis of total sales for each product.
- **Interpretations:** Summary of findings and observations.
- **Dashboard:** Visual overview of key sales performance indicators.

## Project Language
The Excel workbook, dashboard, worksheet titles, and analysis are in Romanian.

## Project Type
Personal learning project.
